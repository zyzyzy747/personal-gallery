# 04 · 云端访问部署（Cloudflare Tunnel）

> 目标：手机在外网也能打开图库，**原图不上传**、**不租服务器**、**不备案**。
> 现状：`https://zyzyzy747.ccwu.cc` 已上线，令牌保护生效，开机自启已配。

---

## 1. 整体链路

```
手机 / 外网
    │  HTTPS
    ▼
Cloudflare 边缘节点
    │  加密隧道（QUIC，出站长连接，无需公网 IP、无需端口映射）
    ▼
本机 cloudflared.exe ──► 127.0.0.1:8777 (serve.py)
                              │
                              ├─ /raw/*     → E:\download\Telegram 原图/原视频
                              └─ 其余        → app/ 下的静态界面与分片
```

**为什么不用服务器**：素材 30.6 GB / 18.8 万个文件。便宜 VPS 磁盘只有 20–40 GB
塞不下，升配到 ¥300–500/年才够；还要上传 30.6 GB 并反复同步；境外 VPS 从国内
访问 1–3 MB/s，比走家里宽带上行还慢。隧道方案零上传、零存储费、原图画质。

## 2. 域名

| 项 | 值 |
|---|---|
| 域名 | `zyzyzy747.ccwu.cc` |
| 来源 | DNSHE 免费二级域名（`ccwu.cc` 后缀给 10 年，到期前 180 天可点免费续期）|
| 到期 | 2036-10-26 |
| 配额 | 单账号 3 个（当前用 1 个）|
| 命名服务器 | `alberto.ns.cloudflare.com` / `lana.ns.cloudflare.com` |

**托管流程**（已完成的记录，重复搭建时照做）：

1. DNSHE 后台注册 `前缀.ccwu.cc`，选 `ccwu.cc` 后缀
2. Cloudflare「添加站点」→ 输入完整域名 → 选 Free 套餐 → 跳过 DNS 扫描
3. CF 给出两个 NS 地址
4. 回 DNSHE 域名详情 → 右上角「DNS服务器」→ 清空系统默认、填这两个 NS、保存
5. 等 CF 显示「活动」
   - 验证方法：`nslookup -type=soa 你的域名 223.5.5.5`
   - **SOA 的 primary name server 变成 `xxx.ns.cloudflare.com`，说明 CF 已接管**

**⚠️ 免费域名的三个风险**（已评估，接受）：
1. 顶级域 `ccwu.cc` 归 DNSHE，你只租用子域，平台可改规则或关停
2. 整个 `ccwu.cc` 被 threatcluster.io 标为 IOC（大量子域用于 C2），
   部分安全软件/运营商可能拦截
3. **不需要 ICP 备案**——备案看服务器位置，源站在自己家、入口在 CF 境外节点，
   且是持令牌的私有服务，不构成面向公众的信息服务

## 3. 隧道配置

**文件**：`C:\Users\Administrator\.cloudflared\config.yml`

```yaml
tunnel: d8559f49-e80c-4a52-b1be-ec3a3ca69a9e
credentials-file: C:\Users\Administrator\.cloudflared\d8559f49-....json
loglevel: info
logfile: D:\work\workbuddy\2026-10-25-19-09-03\tools\service.log
no-autoupdate: true
ingress:
  - hostname: zyzyzy747.ccwu.cc
    service: http://127.0.0.1:8777
    originRequest:
      connectTimeout: 30s
  - service: http_status:404
```

**已执行的命令**：

```bash
cloudflared tunnel login                    # 浏览器选域名授权 → 生成 cert.pem
cloudflared tunnel create gallery           # 得到 tunnel id 和凭据 json
cloudflared tunnel route dns gallery zyzyzy747.ccwu.cc   # 自动建 CNAME
```

## 4. 开机自启

**没装成 Windows 服务**：`service install` 需要管理员权限（`Access is denied`），
且 `sc.exe` 在沙箱黑名单里。改用启动文件夹方案，不需要任何权限。

**文件**：`启动文件夹\PhotoGallery.bat`（源文件 `项目根\后台服务.bat`）

启动顺序（**串行**，有原因）：
1. `build.py` 增量重建索引 → 完成后
2. `serve.py 8777`
3. `cloudflared tunnel run gallery`（并行，连不上会自动重试）

> 为什么 build 和 serve 必须串行：如果 serve 在 build 写 `index.final.json`
> 的中途启动，访问者可能读到写了一半的索引。

**脚本用绝对路径**：因为要复制到启动文件夹，`%~dp0` 在那里会指向启动目录。

**关闭自启**：删掉启动文件夹里的 `PhotoGallery.bat` 即可。

**查看日志**：`last-build.log` / `last-serve.log` / `tools\service.log`

## 5. 访问方式

```
https://zyzyzy747.ccwu.cc/?t=AUDhy1wq1_0B     ← 首次带令牌
https://zyzyzy747.ccwu.cc                      ← 之后靠 Cookie，1 年内有效
```

令牌文件：项目根 `.gallery-token.txt`（`serve.py` 启动时打印，并**复用**旧令牌，
不会每次重启都变）。

**令牌规则**（`serve.py` 的 `_authed`）：

| 来源 | 行为 |
|---|---|
| `Host` 为 127.0.0.1 / localhost | 直通 |
| 外部 + `?t=<令牌>` | 302 到干净 URL + 种 1 年 Cookie |
| 外部 + Cookie `gt=<令牌>` | 放行 |
| 外部无 / 错令牌 | 401 |

`/raw/` 与 `index.final.json` 同样受保护，不能绕过。
